# Currency Exchanger CLI

A simple, object-oriented Python command-line application that fetches real-time exchange rates and converts currencies using the open-source ExchangeRate-API.

## Features

- **Real-Time Data**: Fetches up-to-date currency exchange rates directly from `open.er-api.com`.
- **Robust Error Handling**: Handles network timeouts, connection drops, API errors, and invalid user inputs gracefully.
- **Clean Architecture**: Built using Object-Oriented Programming (OOP) principles in Python.
